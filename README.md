# 🚗 Aluguel de Carros  

## 📋 Descrição Breve  
O projeto **Aluguel de Carros** é uma aplicação do tipo Console que permite realizar operações básicas de um sistema de aluguel de veículos. É possível verificar o status de locações, realizar o processo de locação de um carro e cancelar uma locação, aplicando conceitos fundamentais de programação orientada a objetos (POO).  

## 🛠️ Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash  
   git clone https://github.com/Gzuuu/aluguel-de-carros.git
   ```  
2. Entre na pasta do projeto:  
   ```bash  
   cd trybank/src  
   ```  
3. Instale as dependências:  
   ```bash  
   dotnet restore  
   ```  

## 💻 Tecnologias Utilizadas  
- **📝 Linguagem**: C#  
- **⚙️ Framework**: .NET  

## ⚙️ Funcionalidades  
- 🔍 **Consultar status** de locações.  
- 🚗 **Realizar locação** de veículos.  
- ❌ **Cancelar locações** em andamento.  

## 🌟 Principais Aprendizados  
- 🧱 Aplicação de conceitos de **programação orientada a objetos (POO)**.  
- 🏗️ Desenvolvimento e utilização de **classes** em C#.  
- 📦 Instanciação e manipulação de **objetos**.  
- 🖥️ Criação de **aplicações em console** utilizando .NET.
